# Too-Squirrely
A c++ project that competing in OSU's FEH2 competition.

# Overview 
Too Squirrely is a fast-paced, arcade-style game developed as a collaborative C++ project at The Ohio State University.

Players take control of a squirrel navigating three North Campus locations, collecting falling peanuts, avoiding Michigan fans, and launching acorns to defend themselves. The objective is to earn as many points as possible while managing limited lives and time.

# My contributions
- Player Movement: Navigate stages by running and jumping to avoid incoming threats.
- Collectibles: Catch randomly falling peanuts to increase your score.
- Combat: Launch acorns to defend against moving enemies.
- Enemies: Avoid Michigan fans moving throughout the stages.
- Multiple Stages: Explore three locations inspired by Ohio State's North Campus.
- Scoring and Survival: Manage lives, time limits, and stage exits while maximizing your score.

# Technologies
- SDP Library
- C++

# Repository Scope
This repository contains selected C++ source files from my individual contributions to the project.

Because Too Squirrely was developed collaboratively, the complete application, dependencies, and project configuration are not included. The source files are provided to demonstrate my programming work rather than as a standalone executable.
